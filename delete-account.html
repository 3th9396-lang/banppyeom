앱에서 바로 지우기

반뼘 앱에서 아래 중 한 곳으로 들어가 계정 삭제를 누르세요. 확인을 체크하고 한 번 더 확인하면 바로 지워져요.

  • 연결 중일 때: 홈 → 설정 → 맨 아래 계정 삭제
  • 헤어진 뒤: 헤어진 뒤 화면 → 계정 삭제
  • 아직 연결 전: 연결하기 화면 → 맨 아래 계정 삭제

앱 없이 요청하기

앱을 지웠거나 들어갈 수 없으면 아래 이메일로 요청해 주세요.

이메일: pantarei.korea@gmail.com

제목에 “반뼘 계정 삭제 요청”, 본문에 로그인한 방법(카카오·Apple)과 앱 닉네임을 적어 주세요. 본인 확인 뒤 10일 안에 지우고 결과를 답장으로 알려 드려요.

계정은 두고 일부만 지우기

계정을 지우지 않고 아래 정보만 따로 지울 수 있어요. 누르면 확인을 한 번 거친 뒤 바로 지워져요.

  • 지난 위치 기록: 홈 → 설정 → 위치 공유 → 위치 공유 내역 → 지난 발자국 보관 끄기. 지난 30일 머문 곳·동선과 연간 리포트용 머문 곳(1년)이 바로 지워져요. 오늘 기록은 남아요.
  • 얼굴 사진: 홈 → 설정 → 우리 사이 → 내 얼굴 → 사진 지우기. 사진 대신 고른 캐릭터로 보여요.
  • 등록한 장소: 홈 → 내 장소 → 장소를 눌러 지우기.

위치를 더는 나누고 싶지 않으면 홈 → 설정 → 위치 공유 → 위치 나누기 그만하기를 누르세요. 바로 상대에게 내 위치가 보이지 않아요. 그 밖의 정보를 따로 지우고 싶으면 위 이메일로 지울 항목을 적어 요청해 주세요. 10일 안에 처리하고 답장으로 알려 드려요.

지워지는 것

  • 계정(카카오·Apple 연결)과 프로필: 닉네임, 애칭, 얼굴 사진·캐릭터, 사귄 날
  • 내 위치 좌표와 머문 곳·이동 기록, 등록한 장소
  • 밸런스게임 답과 결과, 알림 설정, 알림용 기기 토큰, 앱 사용 기록

연결 중이었다면 연결이 먼저 끊기고, 상대 앱에는 “상대가 계정을 지웠어요”라고 보여요. 상대가 쌓은 상대 자신의 기록은 상대에게 남아요.

남는 기록은 기간이 지나면 자동으로 지워요. 앱을 지우기만 해서는 계정과 연결이 지워지지 않으니, 꼭 위 방법으로 계정을 지워 주세요.
